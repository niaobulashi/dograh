## i18n 操作手册
- 新增 `doc/Dograh国际化i18n操作手册.md`：覆盖两类操作——①新增中文条目后同步到其他语种（CLI `trans-from-zh` / i18n Ally 插件）；②新增语种（以 ja 为例，改 `config.ts` 的 `locales`+`localeLabels` 两处 + 建 `messages/ja.json` 空文件 + 跑脚本全量翻译 + 重建镜像）。
- 关键事实复核：`LocaleSwitcher.tsx` 完全由 `config.ts` 驱动（改 config 自动出新选项）；`ui/Dockerfile` 第42行 `COPY ui/messages ./messages` 整目录拷贝，新增语种文件无需改 Dockerfile；后端透传文案（`schemaText.ts`）仅有英文→中文映射，其他语种下回退英文（已知限制）。
- 红线固化：新增语种必改 config 两处；`next build` 跑 tsc+eslint，提交前本地自查。
