## 关键坑（必记）
1. **`getTranslations` 不能进 "use client" 文件**。AST 工具曾按「async 函数 → getTranslations」插到 client 组件的事件回调里，且没有 import → 运行时/构建必炸。已修：EnterpriseModal / HireExpertModal / MCPSection / VoiceSelectorModal / useWebSocketRTC / run[runId]/page 的 6 处内层误插声明全部删除，改复用组件顶层已有的 `useTranslations`。`getTranslations` 只保留在 `layout.tsx`（generateMetadata）、`app/workflow/page.tsx`、`app/handler/[...stack]/page.tsx` 三个真正的 server 文件（均有 `next-intl/server` import）。
2. **`src/app/layout.tsx` 的 metadata 必须用 `generateMetadata()` + `getTranslations`**，模块级 `export const metadata` 里不能调 `t()`。
3. **AST 批量替换曾破坏三元表达式**：`? format(...) : "Start date"` 被替换成 `: {t("startDate")}`（多一层 `{}`、丢外层 `}`）。已在 `WorkflowSettingsSections.tsx` 修复为 `: t("startDate")}`。全仓 `? {t(` / `: {t(` 扫描确认无其他残留。
4. **校验脚本要按扩展名选 ScriptKind**：`.ts` 用 `ts.ScriptKind.TS`，按 TSX 解析会把 `Map<number, number>` 当 JSX，误报 136 个错误（`workflowVersionDiff.ts` 误报即此因）。
5. **不可翻译的技术串黑名单**（`i18n_run.mjs` 的 `shouldSkip`）：URL/邮箱/域名/`...` 占位/`must be used within` 守卫/`{{var}}`/hex 色值/JS 字面量(null,true)/camelCase & snake_case 标识符/点号路径/`kebab-case`/函数调用 token `xxx()`/`React:` 这类代码标签/短全大写(US,KB,MB,POST,v)/纯小写单词/长度 ≤2。注意 `(see below)` 这类带空格的散文**不能**因括号被误杀——所以只跳过 `()` 空括号与整串函数调用 token。
6. `ui/i18n-fragments/` 确认是死代码（`src/i18n/request.ts` 只加载 `messages/${locale}.json`），全仓无任何引用。仍保留历史改动未回滚。

## 「只维护中文 + 一键翻译其他语种」工具选型结论
- 源语言固定 `zh-CN`（`src/i18n/config.ts` 的 `defaultLocale`），现有目标 `en`。
- 加新语种必须**同时**：① 在 `src/i18n/config.ts` 的 `locales` 数组与 `localeLabels` 里登记；② 放 `messages/<locale>.json`。Dockerfile 已 `COPY ui/messages ./messages`，无需改。
- 推荐：**i18n Ally**（VS Code/Cursor 插件，`sourceLanguage` 必须设 `zh-CN`，侧边栏 Translate All 一键补齐）；要进 CI 就用 **attranslate**（`--srcLng=zh-CN --matcher=icu`，保留人工修正不覆盖）。
- 数据基线：zh-CN 共 **2555 个叶子**，其中 **166 条含 `{var}` ICU 占位**、**8 条含 `plural`**。中文 plural 只有 `other` 分支（如 `{count, plural, other {# 条录音}}`），译成英文需补 `one/other` 两分支 → 这 8 条必须人工过一遍。
- 另有 `<key>...</key>` 自定义标签（如 `Telephony.telnyxWebhookKeyWarning`）和专有名词（BigQuery / Dograh / MCP / WebRTC / Telnyx），需配 glossary 白名单，否则会被译坏。
